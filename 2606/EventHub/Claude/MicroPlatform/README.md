## Команды

```bash
cd MicroPlatform
dotnet build
dotnet test
dotnet run --project src/MicroPlatform.Demo
```

Ожидаемо: `dotnet build` — без ошибок; `dotnet test` — 6 тестов, все зелёные;
`dotnet run` печатает две строки о публикации `OrderPaid` и резервировании инвентаря.

## Что внутри и почему именно так

- **`IMicroEventBus`** — три метода, ничего лишнего.
- **`InMemoryMicroEventBus`** — потокобезопасен (`ImmutableList` вместо `List<T>`
  внутри `ConcurrentDictionary`), один упавший обработчик не блокирует остальных
  (собираются в `AggregateException`). Это фиксы багов, которые мы находили
  в предыдущих версиях этого же кода в диалоге.
- **`OrderProcessor` / `InventoryProcessor`** — обычные классы, без кодогенератора.
  Каждый хранит **один и тот же экземпляр делегата** в поле и использует его и для
  `Subscribe`, и для `Unsubscribe` — это единственный надёжный способ добиться,
  чтобы `Unsubscribe` реально сработал (раньше в диалоге `Unsubscribe` создавал
  новую лямбду и ничего не находил).
- **`RecordingMicroEventBus`** (только в тестах) — **декоратор**, а не замена шины:
  он и записывает события, и реально их диспетчеризирует дальше. Более ранняя
  версия `TestMicroEventBus` в этом диалоге только записывала, но не вызывала
  обработчиков — из-за этого ни один golden-тест не мог сработать в принципе.
- **Тесты** — `InMemoryMicroEventBusTests` проверяют саму шину (диспетчеризация,
  отсутствие подписчиков, изоляция исключений, `Unsubscribe`). `ProcessorCompositionTests`
  проверяют реальную композицию `OrderProcessor → InventoryProcessor` через настоящую
  шину, включая end-to-end тест с переопределённым виртуальным обработчиком
  (`ObservableInventoryProcessor`) — без "магии" `dynamic`, без рассинхронизации имён
  свойств, которая ломала контрактные тесты в предыдущих версиях.

## Чего здесь сознательно нет (пока)

- Кодогенератора — вернёмся к нему только после того, как это ядро подтверждено рабочим.
- RabbitMQ / MassTransit — это Путь B, следующий шаг.
- Retry/DLQ/reconnect — тоже Путь B, и там это будет отдано MassTransit,
  а не написано руками поверх `IModel`/`AsyncEventingBasicConsumer`.
