# Forgejo

## Суть
Легкий форк Gitea. Выбор для тех, кто хочет, чтобы Git «просто работал» на собственном сервере.

## Плюсы
- **Самый простой:** Разворачивается одной командой Docker.
- **Самый дешевый в содержании:** Потребляет всего 512 МБ RAM.
- **Совместимость:** Forgejo Actions на 95% совместим с GitHub Actions.

## Минусы / Нюансы
- Не входит в Реестр российского ПО.
- Нет встроенных SAST/DAST (сканирование безопасности).
- Требует базового понимания Docker/серверов.

## Вердикт для вас
Идеален как бэкап-цель для зеркалирования из GitVerse на ваш Windows Server 2025.
